# 화면번역 (ScreenTranslator) v0.1

떠 있는 **번역** 버튼을 누르면 지금 화면의 영어/일본어/중국어를 한국어로 덮어씌워 주는 안드로이드 앱.
OCR·번역 전부 구글 ML Kit(폰 안에서 처리, 무료, API 키 없음).

---

## 1. 안드로이드 스튜디오 설치 (PC, 처음 1번)

1. https://developer.android.com/studio 에서 다운로드 → 설치 (기본값으로 계속 Next)
2. 처음 실행하면 SDK 다운로드 화면 나옴 → **Standard** 선택 → 다 받을 때까지 기다리기 (몇 GB, 10~30분)

## 2. 프로젝트 열기

1. `ScreenTranslator.zip` 압축 풀기 (경로에 한글 없는 곳 추천, 예: `C:\dev\ScreenTranslator`)
2. 안드로이드 스튜디오 → **Open** → 압축 푼 `ScreenTranslator` 폴더 선택
3. 오른쪽 아래 **Gradle sync** 끝날 때까지 기다리기 (첫 회 5~10분)
   - "Upgrade Android Gradle Plugin?" 같은 팝업 → 무시하거나 그대로 진행해도 됨
   - 에러 나면 빨간 메시지 복사해서 클로드한테 붙여넣기

## 3. 폰에 설치 — 둘 중 편한 걸로

### 방법 A. USB로 바로 실행 (추천)
1. 폰: **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 연타** → 개발자 모드 켜짐
2. 폰: **설정 → 개발자 옵션 → USB 디버깅 ON**
3. USB로 PC 연결 → 폰에 "USB 디버깅 허용?" 뜨면 허용
4. 안드로이드 스튜디오 위쪽 기기 목록에 폰 이름 뜨면 **▶ Run** 클릭

### 방법 B. APK 파일 뽑아서 설치
1. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
2. 끝나면 뜨는 알림에서 **locate** → `app-debug.apk`
3. 카톡 나에게 보내기 / 구글 드라이브 등으로 폰에 옮겨서 실행 → "출처를 알 수 없는 앱" 허용

## 4. 사용법

1. 앱 열기 → **원문 언어** 고르기 (영어/일본어/중국어)
2. **번역 엔진** 고르기
   - **AI 빠름**: 폰에서 글자를 찾고 글자만 보냄 → 빠름. 한 번 번역한 문장은 저장돼서 즉시 표시. 가로글씨용
   - **AI 정밀**: 고품질, 세로쓰기·말풍선 OK. [aistudio.google.com](https://aistudio.google.com)에서 API 키 발급 → 앱의 키 칸에 붙여넣고 **저장**. 화면 캡처가 구글로 전송되니 은행 앱 등에선 쓰지 말 것
   - **오프라인 (ML Kit)**: 인터넷 없이 동작, 품질 낮음 → **② 오프라인 번역 모델 받기** 필요 (언어당 약 30MB)
3. **① 다른 앱 위에 표시 권한** → 화면번역 ON
4. **▶ 번역 버튼 띄우기** → 화면 녹화 허용 창에서 **"전체 화면"** 선택 (앱 하나만 선택하면 위치가 어긋남)
5. 번역하고 싶은 앱으로 가서 파란 **번역** 버튼 탭 → 1~2초 후 번역문이 덮어씌워짐
6. 아무 데나 탭하면 닫힘. 버튼은 드래그로 옮길 수 있음
7. 끄기: 알림창의 **끄기** 또는 상단 녹화 표시에서 공유 중지

## 알려진 한계 (v0.1)

- 번역 결과 언어는 한국어 고정
- 화면을 스크롤하면 번역 박스는 그대로 남음 → 빈 곳 탭해서 닫고 새로 번역
- 번역 박스는 끌어서 이동 가능 (원문 확인용)
- 번역 버튼 꾹 누르기 → 영어/일본어/중국어, 엔진(정밀/빠름/오프라인), 영역 선택 ON/OFF
- 영역 선택 ON: 버튼 탭 → 영역 드래그(안쪽 끌면 이동, 마지막 영역 기억) → 버튼 다시 탭하면 전송
- 번역 중 버튼 탭 → 중지
- 오프라인 엔진은 세로쓰기·작은 글씨·특이한 폰트 인식이 약함 (AI 엔진 권장)
- 아이폰은 OS 제한으로 불가

